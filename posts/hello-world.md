This is the first post published through seb.now's own pipeline: a Markdown
file in this repo, rendered to a static page at build time, and picked up
by a small ingest function so it shows up in the feed exactly like any
other link — voteable, greyable-on-visit, all of it.

No CMS, no login. To publish, add a `.md` file under `posts/` with a
frontmatter block (`title`, `date`, `description`, optionally `image`) and
push to `main`.
